📥 ИНСТРУКЦИЯ ПО УСТАНОВКЕ
================================================================================

⚠️ Внимание: Сборка предназначена ТОЛЬКО для русскоязычной аудитории.
Все квесты, гайды и обновления выходят только на русском языке.
================================================================================
📋 ЧТО ВАМ ПОНАДОБИТСЯ

Перед установкой убедитесь, что у вас есть:

   • Minecraft Java Edition (лицензия или офлайн-аккаунт)

   • Лаунчер с поддержкой NeoForge (Legacy Launcher,
    Modrinth App, CurseForge или официальный лаунчер)

   • Java 21 (обязательно для Minecraft 1.21.1)

   • Минимум 8 ГБ ОЗУ (рекомендуется 10–12 ГБ)

   • Скачанный архив сборки с Google Disk
================================================================================
📦 ШАГ 1. СКАЧИВАНИЕ СБОРКИ

    Перейдите по ссылке на Google Disk, указанной в разделе
    «Скачать сборку».

    Скачайте архив Kurisagawa.zip (или .rar) на свой компьютер.

    Распакуйте архив в удобную папку (например, C:\Kurisagawa 1.0.0).

ВАЖНО: Не запускайте игру прямо из архива — сначала распакуйте все файлы.
================================================================================
🧩 ШАГ 2. УСТАНОВКА JAVA 21 (Если установлена, то пропустите шаг)

    Скачайте Java 21 с официального сайта:
    https://www.oracle.com/java/technologies/downloads/#java21

    Установите её, следуя инструкциям установщика.

    Запомните путь установки — он понадобится при настройке лаунчера
    (обычно C:\Program Files\Java\jdk-21).
================================================================================
🚀 ШАГ 3. УСТАНОВКА ЛАУНЧЕРА (ЕСЛИ ЕЩЁ НЕ УСТАНОВЛЕН)

Рекомендуемые лаунчеры:

    Legacy Launcher — https://legacylauncher.ru/ru

    CurseForge — https://www.curseforge.com/download/app

    Modrinth App — https://modrinth.com/app

    Официальный лаунчер — https://www.minecraft.net/download

Для офлайн-аккаунтов лучше использовать Legacy Launcher.
================================================================================
🚀 УСТАНОВКА СБОРКИ В ЛАУНЧЕР
================================================================================

🇦 ВАРИАНТ A: CURSEFORGE

Способ 1: Импорт через ZIP-архив

    1. Создайте новый профиль в CurseForge:

        Версия Minecraft: 1.21.1

      • Модлоадер: NeoForge

    2. Откройте папку профиля (правой кнопкой → «Open Folder»).

    3. Скопируйте папки mods, config, resourcepacks, shaderpacks, kubejs
    из архива сборки в папку профиля.

    4. Запустите игру.

🇧 ВАРИАНТ B: MODRINTH APP

    1. Создайте новый инстанс в Modrinth App:

      • Версия Minecraft: 1.21.1

      • Модлоадер: NeoForge

    2. Откройте папку инстанса (кнопка «Open Folder» в настройках).

    3. Скопируйте папки mods, config, resourcepacks, shaderpacks, kubejs
    из архива сборки в папку инстанса.

    Запустите игру.

🇨 ВАРИАНТ C: LEGACY LAUNCHER

Ручная установка модов

    1.Создайте новую сборку в Legacy Launcher:

      • Версия Minecraft: 1.21.1

      • Модлоадер: NeoForge

    2. Откройте папку сборки (кнопка «Папка» в настройках).

    3. Скопируйте папки mods, config, resourcepacks, shaderpacks, kubejs
    из архива сборки в папку сборки.

    Запустите игру.

🇩 ВАРИАНТ D: РУЧНАЯ УСТАНОВКА (ДЛЯ ОПЫТНЫХ)

    1. Установите Minecraft 1.21.1 через любой лаунчер.

    2. Установите NeoForge 1.21.1 с сайта: https://neoforged.net

    3. Скопируйте папки mods, config, resourcepacks, shaderpacks, kubejs
    из архива в папку .minecraft.
    4.Запустите игру через профиль NeoForge.
================================================================================
⚙️ ШАГ 5. ПЕРВЫЙ ЗАПУСК

    Запустите игру и дождитесь полной загрузки кастомного меню (первый запуск может занять
    5–10 минут).

    Создайте новый мир или подключитесь к серверу.

    Если что-то не работает — проверьте логи в папке logs и убедитесь, что:

        Java 21 установлена правильно.

        Выделено достаточно ОЗУ.

        Все моды из папки mods на месте.
